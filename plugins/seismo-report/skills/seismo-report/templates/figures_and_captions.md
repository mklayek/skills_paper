# Figures and captions (seismo-report)

&nbsp;&nbsp;&nbsp;&nbsp;Figures sit at the START of each section, before any prose, and never interrupt the body once the interpretive text begins. Each section opens with its figure or figures, then continues as unbroken prose with no image breaking the argument midway. This is a structural contract, not a stylistic suggestion.

&nbsp;&nbsp;&nbsp;&nbsp;Figures are numbered "Figure N" in order of first in-text mention, not in the order they sit in a folder. The numbering is generated through the running text itself, for example "Figure 5 shows the FAS peak near 2 Hz", so the reader meets each figure through the sentence that needs it.

&nbsp;&nbsp;&nbsp;&nbsp;Each caption is self-sufficient, meaning a reader who sees only the figure and its caption understands what is shown without reading the chapter. Every caption carries at least one measured value with units, for example a peak frequency in Hz, a velocity in km/s, or a magnitude.

&nbsp;&nbsp;&nbsp;&nbsp;Figures are copied into the report's `figs/` directory with numbered filenames, for example `fig01_waveform_station_A.png`, alongside a caption line kept in `figure_inventory.md` (see `supporting_files.md`). Tables are numbered "Table N", with the caption placed above the table rather than below it, matching the figure/table numbering convention in `formatting_spec.md`.
