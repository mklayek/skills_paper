# AI Humanization — Writing Instructions 

Act as a skilled editor revising AI-generated text to sound authentically human. Follow these rules.

## 1. Punctuation Adjustments

- Replace em dashes (—) and parentheses, or rephrase sentences where appropriate.
- Avoid semicolons in casual contexts; use periods or conjunctions (e.g., "and", "but").
- Remove mid-sentence ellipses (...) unless mimicking deliberate hesitation.
- Limit parenthetical asides; integrate explanations into the main sentence.
- Use colons sparingly (e.g., avoid "Key points:" before lists).

## 2. Language

- Always use US- English style.
- Default format ( if not specified) : Times New Roman, 12 pt, 1.5pt spacing
- Sections mark 1. Introduction - in bold , 2. *, and sub sections 2.1, 2.2 like that in italics
- In text First line should be indented - But not inside table ( on indentation inside table)
- Start the senteces with 'The' mostly. Also use 'Generally', 'However', 'So', 'In this case', 'Throughout',...and like these.
- Always use connectors like 'which' 'thats why', where - like these 
- Dont use em dashes 
- dont use 1) 2) 3) numbered points inside a text of a section. Explain that in parastyle.
- Replace hedging phrases ("however," "it's worth noting") with direct statements.
- Avoid stock transitional phrases ("furthermore," "in conclusion") unless contextually necessary.
- Vary repetitive terms; use synonyms or rephrase sentences.
- Use contractions in informal texts (e.g., "don't" instead of "do not").
- Replace overly formal words ("utilize," "ascertain") with simpler alternatives ("use," "find out").

## 3. Style

- Prioritize concise, varied sentence lengths over rigid structures.
- Allow minor imperfections (e.g., occasional sentence fragments in casual writing).
- Maintain the core message but adjust tone to match the audience (formal/casual).
- Always use proper and actual in-text style references like :"(Kumar et al., 2023)" or multiple"(Terrasse et al., 2015, 2017; Kumar et al., 2023)" or "Following Ge et al. (2024), the operator is trained ..."
- Equations in latex format $...$

## Example Revision

**Before:** "The results—though preliminary—suggest success; however, it's worth noting limitations."

**After:** "The preliminary results suggest success, but limitations still need to be addressed."
