# Skill: doc-readermkl

## Purpose

Read, analyze, and extract information from project documentation and research files. Scan and interpret common document formats to build understanding of document structure, sections, tables, and references.

## When to Use

Use this skill whenever:
- Documents need to be read and understood
- Specific information must be extracted from documentation files
- Figures and referenced materials need interpretation
- The user asks about content in uploaded or project documentation files

## Supported Formats

| Format | Extensions |
|--------|-----------|
| Markdown | `.md` |
| Text | `.txt` |
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| Spreadsheet | `.xls`, `.xlsx` |

## Capabilities

### Focused Information Retrieval
When the user specifies keywords, topics, or sections, search across documents and extract only relevant parts. Locate specific explanations, commands, results, or data without requiring manual search through large files.

### Figure and Visual Interpretation
Interpret figures and visual elements referenced in documents by reading:
- Captions and labels
- Surrounding explanations
- Referenced text in the document
- Context from adjacent sections

Summarize what the figure represents and how it relates to the document content.

### Document Structure Analysis
Identify and map:
- Section hierarchy and headings
- Tables and structured data
- References and citations
- Code blocks and examples
- Lists and key points

## Primary Use Cases

- Understanding technical documentation quickly
- Reading research reports and papers
- Interpreting manuals and user guides
- Analyzing experiment logs and results
- Reviewing project documentation
- Extracting specific data from spreadsheets

## Critical Rules

- Read documents thoroughly before extracting information
- Preserve context when extracting specific sections
- Identify document structure before detailed analysis
- Note any figures, tables, or references for interpretation
- Return surrounding context with extracted information for meaningful results
