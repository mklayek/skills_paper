# Global Rules and Checklists — one-page quick reference

## Section order (journal-style IMRaD for archaeological GPR)

Title / Authors / Affiliation / Keywords -> Abstract -> **1. Introduction** -> **2. Study Area and Archaeological / Historical Context** -> **3. Geological and Site Setting** -> **4. Materials and Methods** (4.1 Data Acquisition, 4.2 Processing, 4.3 Time-slice / Depth-slice and Depth Conversion) -> **5. Results** -> **6. Interpretation** -> **7. Discussion** -> **8. Conclusions** -> Acknowledgements -> References -> Figure Captions -> Tables -> Supplementary.

## Tense table

| Section | Tense |
|---|---|
| Abstract | Present for scope, past for what was done |
| Introduction | Present for facts, past for history |
| Study Area / Context | Past for history, present for what exists |
| Geological Setting | Present |
| Methods (Acquisition, Processing) | Past passive |
| Equations | Present for the relation, past for the value used |
| Results | Present for the figure, past for the survey action |
| Interpretation | Present for readings, past for validating actions |
| Discussion | Present-perfect for cumulative, present for verdicts |
| Conclusions | Present |

## Do / Don't

| Do | Don't |
|---|---|
| Ground archaeological context before the technique | Bury Methods in the Introduction |
| Fuse results with interpretation | Defer all interpretation to a standalone block |
| Cross-check every number against an independent source | Write "consistent" without the magnitude |
| Report negative results plainly | Hide detection failures |
| Hedge each claim to its evidentiary tier | Claim confirmation for an unexcavated anomaly |
| Close on the archaeological question | End on a bare geophysical value |
| Define feature vocabulary on first use | Re-explain jargon in Results |
| Self-cite for method continuity | Re-derive an established method |

## Humanization one-liners

- US English. No em dashes (rephrase). Avoid semicolons (period, "and", "but"). No mid-sentence ellipses.
- Limit parentheticals. Colons sparingly.
- Headings bold "1. Introduction", subsection labels italic "2.1".
- Indent every paragraph first line, except inside tables.
- Open sentences mostly with "The / Generally / However / So / In this case / Throughout" and vary them.
- Connectors "which / where / that's why". No 1) 2) 3) lists in section prose.
- Cut hedging filler ("it's worth noting") and stock transitions ("furthermore", "in conclusion"). State it directly.
- Vary repeated terms. Default format Times New Roman, 12 pt, 1.5 spacing.

## Figure / Table / Equation / Citation rules

- **Figures.** Refer to as "Figure N". Captions self-sufficient and interpretive, carrying at least one quantified value. Inline near first citation for journals, batched at end only for camera-ready proceedings.
- **Tables.** Optional in this genre. Use a survey-parameters table and a feature-inventory table for a full journal article.
- **Equations.** Displayed in `$$...$$` with `\tag` numbering and blank lines around, symbols defined immediately after, inline symbols in `$...$`. Minimum set for a full journal Methods: depth $d = v t / 2$, velocity $v = c / \sqrt{\varepsilon_r}$, and the depth-slice amplitude quantity.
- **Citations.** Author-date, alphabetical, unnumbered list. Forms `(Kumar et al., 2023)`, `(Terrasse et al., 2015, 2017; Kumar et al., 2023)`, `Following Ge et al. (2024)`. Cite physics of inferences, not the archaeology. Self-cite for method continuity. Grey literature on equal footing. Roughly 15 to 40 references for a full article.

## 5-tier evidentiary-validation hierarchy

1. **Excavation-confirmed** — "was confirmed by excavation", "revealed".
2. **Strongly-supported** — "agrees with the dimensions recorded by", "is consistent with", "as predicted by".
3. **Probable** — "is believed to be", "most probably represents".
4. **Possible** — "may correspond to", "may be related to", "perhaps".
5. **Unconfirmed** — "indicate the presence of", "an area that would repay future excavation".

Never use Tier 1 language for a Tier 4 or Tier 5 anomaly. Read meaningful absences as classifications, not discarded nulls.

## Final pre-submission checklist

- [ ] Canonical section order followed, abstract present for a journal.
- [ ] Historical and archaeological context precedes the technique.
- [ ] Feature vocabulary defined on first use, abbreviations defined on first use.
- [ ] Methods is a headed section with acquisition, processing, and depth conversion.
- [ ] Velocity value, its origin, and the depth relation stated.
- [ ] What was not done is named and justified.
- [ ] Results mirror the Methods order and report negatives plainly.
- [ ] Every quantitative claim cross-checked with a stated magnitude.
- [ ] Every archaeological claim placed on exactly one tier with matching hedge.
- [ ] Discussion and Conclusions exist as explicit sections.
- [ ] Paper closes on the archaeological question.
- [ ] Equations in `$$...$$` with numbering and defined symbols.
- [ ] Reference list alphabetical and unnumbered, self-citation and grey literature included, every in-text cite resolves.
- [ ] Captions self-sufficient with a quantified value, archetypal figure set present.
- [ ] Humanization gate passed: no em dashes, semicolons avoided, no filler or stock transitions, openers varied, paragraphs indented.
- [ ] Default author block embedded at the top.
- [ ] Document set to Times New Roman, 12 pt, 1.5 spacing.
